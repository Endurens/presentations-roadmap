MCP — мост для нейронки

MCP (Model Context Protocol) — протокол-«переходник», который подключает нейронку к вашим программам: Figma, файлам, сайту.
Мост→соединяет ИИ с внешними инструментами
Руки→нейронка не только отвечает, но и делает: читает, меняет, сохраняет
Сервер→каждая программа даёт свой MCP-сервер — свой набор действий
Не просто чат — помощник с руками
MCP-серверы

Figsor — MCP для Figma

Figsor — это MCP-сервер для Figma: подключается к opencode и даёт нейронке прямой доступ к вашим макетам в Figma.
Читает→видит слои, тексты и стили макета так же, как вы
Меняет→правит макет по вашему промпту — без ручной возни
Записывает→сохраняет изменения прямо в Figma
Всё делает opencode — вы даёте промпты и контролируете каждое действие.
Figma × MCP

GitHub — что это?

GitHub — это облачный склад для файлов проекта + соцсеть для команд. Как Google Диск, только заточен под код и историю изменений.
Хранение→ваш проект лежит в облаке и не потеряется
История→видно, кто, когда и что менял
Обмен→можно показать работу миру или команде
Склад + дневник + соцсеть
GitHub

Репозиторий — папка проекта

Репозиторий — это папка вашего проекта, у которой есть память. Внутри — все файлы и вся история их изменений с самого первого дня.
Файлы→код, картинки, тексты — всё в одном месте
Память→можно вернуться к любой старой версии
Копия→скачал на компьютер — работаешь без интернета
Папка, которая помнит всё
Репозиторий

Коммит — точка сохранения

Коммит — это снимок проекта в конкретный момент. Как сохранение в игре: сделал шаг — сохранился. Ошибся позже — откатился к сохранению.
Снимок→фиксирует файлы «как есть сейчас»
Подпись→к каждому — короткое описание: что поменял
Откат→всегда можно вернуться назад
Сохраняйся часто — не бойся ошибок
Коммит

GitHub Pages — твой сайт в интернете

GitHub Pages — бесплатный хостинг прямо внутри GitHub. Он превращает файлы из репозитория в живую веб-страницу по ссылке.
Живая ссылка→страница открывается с любого устройства
Бесплатно→не нужен сервер и оплата хостинга
Портфолио→ссылку можно скинуть друзьям и в резюме
Залил в репозиторий — ты в интернете
