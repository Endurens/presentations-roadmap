Аудит — детектив

Аудит — осмотр всего проекта без единого изменения кода. opencode читает файлы и складывает найденное в таблицу AUDIT.md: проблема → файл:строка → серьёзность → что делать.
Секреты→токены, ключи, пароли прямо в коде — светятся в git-истории
Мусор→дубли, мёртвый код, баги, потеря данных, уязвимости
Хаос→разные шрифты, съехавшие отступы, цвета не из палитры
Аудит не меняет ни строчки
Аудит

Серьёзность проблем

P0→критично: упало или небезопасно — чек пропал, токен в коде
P1→важно: дубли, мёртвый код, потеря данных, небезопасная зависимость
P2→желательно: шрифт не тот, отступ съехал, цвет не из палитры
Сначала работа, потом эстетика
P0 → P1 → P2

Рефакторинг — лекарь

Рефакторинг исправляет найденное аудитом, не меняя внешнего поведения: пользователь видит то же самое, а внутри код чище.
Поведение→для пользователя всё работает как раньше
Устройство→дубли свёрнуты, мёртвый код удалён, имена понятные
Ритм→одна правка → проверка → коммит, порядок P0 → P1
Ничего нового — только чистка
