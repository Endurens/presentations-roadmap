Разведка: скан образца

Прежде чем строить — смотрим, как сделано у лучших. Подберите сайт-ориентир под наш проект, и OpenCode соберёт по нему отчёт.
Дизайн→цвета, шрифты, стиль оформления
Структура→шапка, герой, преимущества, кнопка действия, подвал
Тексты→какие обещания и формулировки использует продукт
Функционал→как устроена главная кнопка страницы
Ничего не создаёт — только доклад
Блок 1 · разведка

Моё описание: досье

Досье→что за продукт, для кого, какие разделы на странице
Преимущества→минимум три, каждое — конкретная выгода, не «это удобно»
grillme→жарит досье трудными вопросами, вскрывает слабые места
Копирайтер→маркетолог переписывает тексты так, чтобы читались
Готового промпта нет — пишете вы
Блок 2 · моё описание

Архитектура: план

Секции→какие блоки будут на странице и что в каждом
Тексты→какой текст к какому блоку — уже усиленные
Стили→цвета, шрифты, оформление: своя система, не копия
Интерактив→кнопки, ссылки, формы: что нажимается и куда ведёт
План дёшево — страницу дорого
Блок 3 · архитектура

OpenCode собирает

Страница пишется файлами прямо в рабочую папку проекта: index.html в корне, рядом css/, js/ и картинки. Папка и есть сайт.
Ссылки→только относительные: css/style.css — никаких file://
Правки→промптами: «сделай заголовок крупнее» — по одной задаче
Черновик→двойной клик по index.html — страница видна в браузере
Что открылось локально — откроется в сети
Блок 4 · сборка

Независимый аудит

Новая вкладка→аудитор не автор страницы и не жалеет её
Дизайн→цвета, отступы, шрифты, читаемость
Тексты→опечатки, скучные и пустые формулировки
Функционал→кнопки, ссылки, сломанные элементы
Отчёт→«что не так — почему — как исправить», по серьёзности
Свежий контекст не жалеет
Блок 5 · аудит

Рефакторинг

По порядку→от серьёзных ошибок аудита к мелким
Мусор→лишние стили, дубли, мёртвые кнопки — под нож
Смысл→не меняется: всё, что работало, продолжает работать
Отчёт→«что исправлено — что удалено», по пунктам аудита
Лендинг готов — пока на диске
Блок 6 · рефакторинг

Часть 2: деплой на Amvera

Amvera (amvera.ru) — российская PaaS-платформа: сайт разворачивается в контейнере, а код доставляется push'ем в Git или загрузкой через личный кабинет. Наша часть в этой части — аккаунт. Всё остальное в кабинете сделает агент.
GitOps→обновление одной командой: git push amvera master
Домен и SSL→бесплатный адрес *.amvera.tech с HTTPS-сертификатом
Тариф→«Пробный»: 170 ₽/мес поминутно, 111 ₽ на тест при регистрации
Регионы→Москва, Варшава, Майами
Серверы — не ваша забота
Блок 7 · знакомство

Playwright — руки агента

Playwright — фреймворк автоматизации браузера от Microsoft: он управляет настоящим браузером, как человек. Навык playwright делает его ролью агента: OpenCode сам открывает кабинет Amvera и ведёт деплой от начала до конца.
Playwright→открывает страницы, кликает, заполняет формы, грузит файлы
Навык playwright→агент ведёт браузер сам — вы только смотрите
Скриншоты→агент видит страницу и проверяет результат глазами
Ваша роль→создать аккаунт — дальше руль у агента
Мышка не нужна
Блок 8 · playwright

Регистрация: наш ход

Кабинет→cloud.amvera.ru → кнопка «Зарегистрироваться»
Вход→через Google или GitHub — быстрее всего
Баланс→111 ₽ стартовых активируются автоматически
Сессия→войдите и оставьте кабинет открытым — агент подхватит его через playwright
Единственное действие руками
Блок 9 · регистрация

Проект: делает агент

Создание→агент сам нажимает «Создайте первый проект!»
Тип и регион→«Приложение», регион — Москва или подходящий
Имя и тариф→латинское название, тариф «Пробный» для старта
Дальше→этап «Загрузка данных» — тоже на агенте
Имя станет частью адреса
Блок 10 · проект

amvera.yaml: один файл

Генератор→manifest.amvera.ru сгенерирует файл за вас
Окружение→Node.JS Browser (Static Web) — для статических сайтов
В корень→рядом с index.html: конфиг хранится вместе с кодом
Кто кладёт→агент: сгенерирует и положит сам, без вашего участия
Писать руками не нужно никому
Блок 11 · конфигурация

Загрузка кода: сам агент

Загрузка→агент перетаскивает файлы лендинга в окно кабинета через playwright
Проверка→дожидается, пока всё появится в списке — ничего не потерялось
Сборка→Amvera собирает и запускает проект сама, без простоя
Обновление→правили файлы → агент перезаливает сам; запасной путь — git push amvera master
Одно сообщение — и сайт новый
Блок 12 · загрузка

Домен и HTTPS

Добавить→агент открывает вкладку «Домены» и берёт «Бесплатный домен Амвера»
Адрес→проект.пользователь.регион.amvera.tech — с HTTPS
Сертификат→выдаётся автоматически, первое открытие — пара минут
Проверка→откройте адрес с телефона — сайт должен открыться
Живой сайт — с телефона
Блок 13 · домен

Аудит, обновление, защита

Аудит по URL→агент проверяет живой сайт как сторонний эксперт
Обновление→правки файлов → повторная загрузка агентом, тот же адрес
Безопасность→цикл «аудит → правки → аудит», максимум 3 цикла
Смысл→при правках не меняется: работало — работает
Публикация — не финиш
